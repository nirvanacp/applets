# Use the @nirvanacp SDK packages

Problem ID: `alpha-release` · Problem: make Genesis publishable and release alpha builds · Spirit animal: 🦩 Flamingo

- Goal: follow the Let framework's rename of its npm packages from the `@let` scope to `@nirvanacp`, and its first publishable version.
- Changes: every `@let/sdk` import under `src/` now names `@nirvanacp/sdk`; `package.json` depends on `@nirvanacp/sdk` `0.1.0-alpha.1`. The current spec names the new package and version. No route, reader, command, service, stored data or behavior changed.
- Decisions: the developer chose the `@nirvanacp` scope and version `0.1.0-alpha.1` for every framework package. The applet version stays unchanged until a pull request raises it and `genesis-applet publish` runs.
- Verification: workspace `typecheck`, `genesis-applet check` and `genesis-applet build` pass with no warnings. Not run on a device: the bundle code is the same apart from the package name.
