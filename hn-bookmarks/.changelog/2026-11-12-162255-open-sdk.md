# Move to the open SDK

- Goal: Run Hacker News on Genesis's open applet SDK as its pilot applet, with the same screens and behavior.
- Changes: `src/page.ts` replaces `src/adapter.ts` with readers and commands over the existing read functions; `src/routes.ts` holds the route table for the router; `src/screen.ts` adds per-screen watch helpers. The UI mounts with `mount` and uses `useRouter`, `useWatch`, `useCommand` and `usePending`. The adapter tests now exercise the page module and the route table.
- Decisions: decision-0009. Commands take `{ id }`-style arguments; the account reader reports no evidence on pages without it, which needed a Genesis router change made separately.
- Verification: `typecheck`, `check`, `build` and 13 tests pass. On the Samsung SM-M307F, signed in: feed, thread, Back, Me, Guidelines, Search results, the Post form and More. Saved showed its service error with the service stopped. Vote, post and sign out were not repeated because they write to HN.
