# Native-feel revamp

Problem ID: applet-revamp
Problem: Revamp every applet with the native-feel guidance
Spirit animal: 🦉 Owl

- Goal: Make the Hacker News applet feel like a native Android app at the quality of the X applet, keeping HN's look (decision-0002), every route, reader, command, storage shape and the bookmarks service.
- Changes:
  - Kit: Stage screen motion, toasts, the delayed progress bar, `useBusy`, pull to refresh, `LoadError` and `WebsiteCue` in `src/ui/`; theme tokens for light, dark and `data-theme`; reduced motion covers `*::before` and `*::after`.
  - Frame: a header row per screen with Refresh and the menu corner clear; the tab bar shows on tab roots only, with filled icons and a pill on the current tab; reselecting returns to the start or scrolls to the top.
  - Home and lists: the feed chips sit in the header; story list or comment list skeleton; "Nothing here yet" with Refresh; More shows a spinner and "Loading more".
  - Discussion: its own skeleton; Add a comment and Read N more show "Opening…" and carry the website cue; "No comments yet" waits for the comments reader; HN's `[–]` and `[+n]` toggle.
  - Stories: votes fail or go unconfirmed in a toast; the arrow pops; article titles carry the website cue after the domain.
  - Profile, info, Search, results, Post, Me: their own skeletons; list rows with chevrons; search fields with keyboard hints; Post and Sign out show spinners for at least 800 ms; "Signed out of Hacker News" toast.
  - Saved, Categories, Save: own skeletons; Manage categories moves to a header button; category writes end in toasts; Remove from Saved is immediate with Undo; check boxes in HN orange.
  - Fallback fixes: "No results" and "No comments yet" no longer show before their readers have read the page.
  - README: Search is no longer described as a placeholder.
- Phone fix: the header chips get a right-edge fade and padding, so a chip cut by the screen edge reads as more to scroll.
- Review fixes: Saved shows "Couldn't load saved stories" with Try again, not "No saved stories", when the read failed and nothing is saved; a rejected vote, Add a comment, Read N more or Sign out now ends in its toast or inline error instead of an unhandled rejection; the vote arrows' hit area grows to 48×48 with a transparent `::after`, leaving their drawn size and the layout unchanged. Not checked on a device.
- Decisions: decision-0011 to decision-0014.
- Verification: `npm run typecheck`, `npm run check` and `npm run build` pass. On a phone: Home feed, discussion skeleton then comments, Back, Saved's error with Try again (bookmarks service off), Me. The feed fell back to the website once on a first open and did not repeat on retry. Not checked on a device: dark theme, reduced motion, Save and Remove with Undo, Post, Categories. No tests were changed.
- Release: version unchanged (0.0.4).
