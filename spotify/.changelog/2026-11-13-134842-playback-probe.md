# Playback probe

Problem ID: `spotify-applet` · Spirit animal: 🦜 Parrot

- Goal: show that the applet can read and control Spotify playback through its hidden website, now that Genesis grants protected media to website pages.
- Changes: `src/page.ts` gains reader `nowPlaying` and command `setPlaying` (trusted clicks, Spotify Connect takeover); `src/main.tsx` adds the now-playing strip to screen `home`; `src/theme.css` styles it; `.specs/current.md` and decision-0003 record the results.
- Decisions: a probe instead of PRD screens, at the user's request; play state read from the button's icon because it has no label; trusted input because sound needs a user gesture.
- Verification: `check`, `tsc` and `build` pass. On a Samsung SM-M307F phone (Android 11, Widevine L1), applet Play and Pause control the page's playback and Genesis's media stream. Not verified: the Connect takeover steps (the prompt did not reappear), audibility by ear, and playback in the background (Genesis frees background applets).
