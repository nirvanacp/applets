# Native-feel revamp of the Spotify applet

Problem ID: `applet-revamp` · Problem: Revamp every applet with the native-feel guidance · Spirit animal: 🦉 Owl

- Goal: Make the applet feel like Spotify's Android app under the factory's native-feel guidance, keeping every route, journey, command and the playback controls.
- Changes: Kit theme tokens in Spotify's dark palette; the kit's Stage motion with Now Playing rising and falling; a toast region, progress bar and pull to refresh; one shaped skeleton per destination; shared header, states, and busy-then-outcome actions with Undo for removals; the website cue on Log in, View website and Liked Songs; the menu corner kept clear; the reduced-motion rule fixed to keep states visible.
- Decisions: decision-0006 (dark only), decision-0007 (rise and fall), decision-0008 (toasts and Undo), decision-0009 (no Undo for recent searches), decision-0010 (where refresh applies). The adapters were reviewed and no reader bugs were found.
- Phone fixes: the album and artist bar is fully opaque once solid (rows showed through at 94%); the end of a track list keeps its height, so the list no longer jumps when the load-more spinner goes; search shows "No results" only after the list stays empty for 3 seconds on the same query and filters, since it flashed before Spotify's results arrived.
- Review fixes: Now Playing shows its skeleton until the current track is read, so "Nothing is playing" no longer flashes on open; reselecting a tab scrolls without smooth motion under reduced motion; optimistic controls show the newest pending command instead of the oldest.
- Verification: `check`, `typecheck` and `build` pass.
