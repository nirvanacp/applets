# Discord page module

Problem ID: `discord-applet` · Problem: Build a Discord applet · Spirit animal: 🦔 Hedgehog

- Goal: Read Discord's signed-in pages and act on them for the applet's screens.
- Changes: `src/adapter/` reads the account, the drawer, the server rail, direct messages, a server's channels, the current place, messages (text parts, replies, media, stickers, files, embeds, reactions) and the composer; commands `openDrawer`, `send`, `loadOlder` and `setReaction`. `src/model.ts` holds the shared types and limits; `src/routes.ts` routes `/channels/@me`, `/app`, DMs, channels and servers, and leaves threads on the website.
