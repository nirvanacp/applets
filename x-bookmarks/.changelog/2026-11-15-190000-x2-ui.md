# X takes X2's UI

Problem ID: applet-revamp
Problem: Revamp every applet with the native-feel guidance
Spirit animal: 🦉 Owl

- **Request:** the developer compared X with X2, a separate applet that rebuilt X's UI from the factory's native-feel guide and UI kit, preferred X2, and asked for one X applet.
- **Change:** X2's `src/` replaces this applet's `src/` (decision-0012). The id `x-bookmarks`, the name X, the icons, the `bookmarks` backend on port 8788 and its state, and device storage are unchanged. X2's records (its scaffold, UI build and phone fixes, kept in the collection's git history under `x2/.changelog/`) are folded into decisions 0012 to 0017 and the current spec. The `x2` applet and its port 8789 are removed; its backend state on disk is left alone.
- **Package:** `engines` and the `@genesis/applet-tools` dev dependency match the other applets; the root lockfile drops `x2`.
- **Verification:** `npm run check`, `npm run typecheck` and `npm run build` pass. The phone check follows in a later record.
