# Safe composer retries and honest Show more

- Goal: make a second Post tap after a partial failure safe, so it never types the text twice or attaches a photo twice, and make Show more say what really happened.
- Changes: `composer` now reads X's editor text too. Post reads X's composer first: text that equals the draft is not typed again, photos X already shows are not attached again, and only the missing ones are attached; when X holds other text or more photos than the draft, or any photos after the person changed the draft's photos since an attempt began attaching, Post stops before any input and asks the person to check X's composer. `holdsMedia` needs exactly the draft's count, so a doubled photo no longer counts as attached. The failure text reads X's toast after the attempt instead of the copy from before it. Show more shows "No more posts right now." only when the list stayed put until the deadline, a rate limit message on `RATE_LIMITED`, and a retry message on other failures.
- Decisions: none new; typing appends in X's editor, so the applet reads before it types rather than clearing X's editor. X's composer tells only how many photos it holds, so after the draft's photos change, Post refuses while X still holds any instead of guessing which ones they are; that state clears after a post or when X's composer holds none.
- Verification: `check`, `typecheck` and `build` pass. No device was used; X's composer and the failure paths are implemented, not device-verified.
