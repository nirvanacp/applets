# Categories in a local servelet

Problem ID: let-servelets
Problem: Move the applet framework into Let, add servelets that run on the phone, and move the applets' backends to them
Spirit animal: 🐙 Octopus

- Goal: Run the `bookmarks` service on the phone as the `x-bookmarks` servelet, so Categories work without a computer, a tunnel or a token, with the same endpoints and record shapes.
- Changes: `service.json` declares `runtime: local` with servelet `x-bookmarks`; `applet.json` names it. The Node backend moved to `legacy/backend/` with a README. `ports.json` reserves no port, and the collection launcher no longer mentions `X_EXPECTED_HANDLE`. `library.ts` replaces the `GET /v1/library` read with `open(handle)`, which claims or reads the library once the signed-in account is known, and then reads the categories. The README operator setup and the current spec say the data lives on the phone.
