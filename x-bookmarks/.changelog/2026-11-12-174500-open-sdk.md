# Move to the open SDK

- Goal: Run X on Genesis's open applet SDK with the same screens and behavior, after the Hacker News pilot.
- Changes: `src/page.ts` replaces `src/adapter.ts` with readers and commands over the existing read functions; `src/routes.ts` holds the route table, with website routes for one-segment X paths that are not profiles; `src/screen.ts` adds per-screen watch helpers. Screens use `useRouter`, `useWatch`, `useCommand` and `usePending`; pending state also covers commands sent without arguments.
- Decisions: decision-0007. Like and bookmark take a post id; the account handle comes from its own watch.
- Verification: `typecheck`, `check` (no warnings) and `build` pass. On the Samsung SM-M307F X was signed out: the landing page, the sign-in flow and a signed-out profile showed X's pages as before. Signed-in screens, like, bookmark and Show more were not checked, because no disposable X account is approved.
