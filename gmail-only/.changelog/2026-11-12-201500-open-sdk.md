# Move to the open SDK

- Goal: Run Gmail Only on Genesis's open applet SDK with the same screens and behavior, after Hacker News and X.
- Changes: `src/page.ts` replaces `src/adapter.ts` with readers and commands over the existing read and page functions; `src/routes.ts` holds the two routes; `src/components/page.ts` adds watch and status helpers. Screens use `useRouter`, `useWatch`, `useCommand` and `usePending`. The email and session come from the `view` reader. The More options popover is a router screen, so Back closes it. The applet's sign-in screen is removed.
- Decisions: decision-0015. Signed out, Gmail shows Google's own sign-in page.
- Verification: `typecheck`, `check` (no warnings) and `build` pass. On the Samsung SM-M307F with revision 24, read-only: the inbox with its unread count and avatar, an open email with a collapsed message expanded, Back, the drawer, and the popover closing with Back. Star, select, archive, delete, compose and send were not run, because they change the account.
