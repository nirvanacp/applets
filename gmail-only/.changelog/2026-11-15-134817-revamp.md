# Native-feel revamp of Gmail Only

Problem ID: applet-revamp
Problem: Revamp every applet with the native-feel guidance
Spirit animal: 🦉 Owl

- Goal: Bring Gmail Only to the factory's native-feel bar, the same as X Bookmarks, while keeping every feature, route, journey and stored shape.
- Changes: The UI kit's feedback, states, pull to refresh, skeletons and motion now live in `src/ui/`. `theme.css` adds the missing tokens for light and dark, clears the shell menu corner on every header, and replaces the old skeleton with `.sk` shapes. Every destination has its own skeleton. Every tapped command shows busy and reports failure; the email's Archive has an Undo. The list no longer shows its empty state while loading or after an error, and an error shows Try again and "Open in Gmail". Settings, accounts, item and snoozed screens no longer show defaults or fallback names while loading. The drawer skeleton no longer shimmers forever after an error. Controls that show Gmail carry the website cue. Reduced motion also stops the shimmer and the refresh spin. No reader or page-module bug was found, so `src/page.ts` and `src/adapter/` are unchanged.
- Review fixes: the list shows its load error, not the skeleton, when the threads read fails with nothing to show; Load older emails stops spinning and says so when the command rejects; the list and the selection bar share one progress bar; the archive Undo says so when moving the email back rejects; the email's busy timer is cleared on leaving; the drawer's account card shimmers only while its read loads, and a failed menu read shows a Labels error with Try again; a label row spins as long as its busy state. Not checked on a device.
- Decisions: decision-0016 (UI kit and tokens), decision-0017 (skeletons and truthful states), decision-0018 (busy feedback and Undo scope), decision-0019 (website cue).
- Verification: `npm run check`, `npm run typecheck` and `npm run build` pass. On the phone (signed in): the inbox skeleton then rows, an email opening at once and Back, the drawer with labels and counts, and To-do. Not checked: Archive with Undo (no disposable email was sent), compose, offline errors, dark theme and reduced motion.
- Release: no version change; not published.
- Review fixes re-checked on a phone: the inbox loads, and the drawer shows the account card and label counts. The failure paths were not reproduced on a device.
