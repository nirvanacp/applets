# Use the new manifest

- Goal: Keep the applet building and running after Genesis removed routes, screens and the adapter from `applet.json`.
- Changes: `applet.json` declares `foreground` as `{ "kind": "web", "entry": "index.html" }` and gains a `build` section with the UI entry `src/main.tsx` and the page module `src/page.ts`. The old `routes`, `foreground.screens` and `adapter` fields are gone; the route table already lived in `src/routes.ts`. `src/adapter/pages.ts` uses the SDK's renamed `Step` type.
- Decisions: No version change; `package.json` keeps its version, and `genesis-applet publish` waits for a pull request.
- Verification: `check` (no warnings), `build` and `typecheck` pass. On the Samsung SM-M307F, the previous revision dropped out of the launcher after the new Genesis build was installed, as planned; after `dev install` Gmail Only opened signed in on the inbox, and the To-do tab still showed the item saved before the upgrade.
